# 🏓 Pong - MonoGame

Projeto do jogo clássico **Pong**, desenvolvido utilizando o framework **MonoGame** e a linguagem **C#**. O jogo consiste em dois jogadores controlando barras laterais para rebater a bola e marcar pontos.

---

## 📌 Sobre o Projeto

Este projeto foi criado para estudo e prática de desenvolvimento de jogos utilizando MonoGame, abordando conceitos como:

- Movimentação de objetos 2D
- Detecção de colisões
- Sistema de pontuação
- Lógica de jogo
- Entrada do jogador

---

## 🛠️ Tecnologias Utilizadas

- MonoGame  
- C#  
- .NET  

---

## 🎮 Mecânicas do Jogo

✔ Controle das barras laterais  
✔ Bola com movimentação e rebote  
✔ Sistema de pontuação  
✔ Reinício da bola após ponto  
✔ Detecção de colisão com paredes e jogadores  

---

## 🎮 Controles

| Jogador | Tecla | Ação |
|----------|------------|-----------|
| Jogador 1 | W / S | Mover barra para cima e para baixo |
